# Лабораторна робота №2

Дисципліна: Технології розробки на платформі Java

Тема: Збірка проєкту за допомогою Gradle та робота з Java Collections Framework

## Варіант

Номер залікової книжки: 4110
V = 4110 mod 3 = 0
Варіант-0: Аналізатор логів серверів

## Опис

Проєкт реалізує клас LogAnalyzer для обробки серверних логів у форматі Common Log Format
При однаковій частоті IP-адреси сортуються лексикографічно. Некоректні записи ігноруються.

Методи:
1. getUniqueIps() — повертає множину унікальних IP-адрес.
2. getTopIps() — повертає найчастіші IP-адреси за спаданням частоти.

## Інструкцію для запуску

Для збірки проєкту або запуску тестуванння необхідно відкрити термінал у кореневій директорії проєкту та виконати відповідну команду

Збірка проєкту:

```powershell
.\gradlew.bat build
```

Запуск тестів:

```powershell
.\gradlew.bat test
```
